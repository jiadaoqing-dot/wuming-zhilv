《无名之旅》当前设定(只写现在是什么样;历次改动见《更新记录.txt》)

画风与界面

	•	整体是 Q 版页游卡通风：矢量绘制，粗描边、渐变、大眼睛，HUD 和按钮带金框。
	•	主角、NPC、漫画人物都用 drawChibi 画；怪物画法在 MON 对象里，首领预警在 TELE 里。怪物 / 首领血量倍率 EHP=7（2026-10-12 翻倍），防御 ×1.5（EDF，只在伤害公式里乘；小怪本来没有防御）。首领攻击的预警和特效都是像素素材：地面红色魔法阵 DZ（PVFX 漩涡染红），落石 BTA，沙浪 / 冰刺 / 冲击波 / 毒柱用 VFX 帧。
	•	关卡背景是多层视差，各关的图层提前画到离屏画布（LVA / lvArt / mkL / tileL）。主城是分层视差的宽地图（TWN，见「主城」一条）；世界地图也是提前画好的。世界地图用玩家定制的插画（MAPI，art_src/map/build_map.py，牌子上的字擦掉后由游戏按 MAPS 写关卡名 / 推荐等级 / 锁定 / 通关星，牌子位置 MAPP，鼠标悬停高亮；原来晨曦镇的牌子 2026-10-13 起是第八关「幽魂都市」，地图上不再显示晨曦镇，按 1~8 选关；2026-10-13 第十一轮加第十关「幽灵船」，牌子画在右下角的船身上（MAPP 第 10 个），按 1~9、0 选关）；图没加载好时退回旧的 mapBG。
	•	尺寸：主角绘制比例 HSC=1.05，小怪的碰撞盒和画面一起放大 MSC=1.25，首领画面放大 1.1 倍；在此基础上按「体积」再放大（szF / VSZ，2026-10-12）：小怪 = 玩家的 1.25 倍、首领 = 玩家的 2.25 倍（画面实测 宽×高 开方比较，只放大不缩小；鸵鸟、双头狗、铁角牛魔、北极熊本来就更大，不变）。
	•	关卡推进（2026-10-12）：取消能量屏障墙，改为镜头锁在当前区域（ZB 四个区域），清完本区域（待刷 + 活着的）才能往前走；小怪数量 ×2.5（WMUL），玩家走进区域才刷本区域的怪，分两次从天上掉下来：先掉一半，打完再掉剩下的（第二十九轮，waveStep / waveDrop / mkWQ / WQ / WB）；每只的经验、金币、装备掉率都 ÷2.5，打完一关总量不变。(2026-10-13 第十三轮起关卡里不再显示剩余数量文字牌。)W+空格（绝息风斩）能锁定蝙蝠（lsOk）。没有飞行小怪（FLYK，目前只有蝙蝠）的关卡（三~七关）去掉全部浮空平台，只保留地面、六关冰墙和七关首领场地里的两块。 关卡掉落率减半(第十五轮,DROPK 0.5):小怪装备 / 蛇蛋、首领的 2 件装备和强化石各自 50% 掉;主线物品、转职凭证、女神碎片、仓鼠宠物蛋不变。
	•	电脑端界面整体放大：面板用 CSS 变量 --uiz（约 2.08），菜单按钮用 --tbz（约 1.79），由 uiScale() 按画面宽度计算。面板内容太高时在画面框里滚动。
	•	菜单按钮在右下角：背包、技能、商城、精灵、宠物、任务、签到（今天没签到时有红点）、声音；GM 按钮只在 GM 里打开开关后才显示。画面下方有 ⚙️ 设置按钮。 像素美术时按钮是像素按钮框 + MENI 图标(496 pixel art icons,7Soul1,CC0:喇叭自画 / 锤子 / 时钟 / 卷轴 / 羽毛 / 羽翼 / 金币 / 魔法书 / 宝箱)+ 像素字标签。
	•	设置里能做的：暂停、返回城镇、帧数（60 / 120）、显示帧数、画质、全屏、声音。
	•	HUD：VIP 开通后头像右下角有金色「VIP」标。

操作

	•	基本：A / D 移动，双击快跑（跑步中放技能不打断：技能结束时还按着方向键就继续跑）；K / ↑ 跳；J 攻击，按住蓄力重击；W+J / S+J 是特殊普攻（剑士的 W+J 上挑 / S+J 重击有内置冷却 1.2 / 1.0 秒；击飞初速 760、空中重力 2800，浮空约 0.47 秒）；L 换武器；H U I O 放技能；转职剑士后 空格 / W+空格 / S+空格 / WW+空格（连按两下 W 再按空格）放进阶技能；1 2 3 使用快捷栏药水；S 捡起脚下附近的掉落物。
	•	快捷键：B 背包，T 技能，Q 任务（任务按钮现在一开始就有），P 商城，Y 精灵，G 宠物，M 声音，Esc 打开设置(第四十二轮恢复,设置里「菜单快捷键」可以关闭,SET.hotk);N 放当前武器上嵌的怪物技能石。
	•	主城（2026-10-12 扩大，TWN，art_src/town/build_town2.py）：宽 1600（普通关卡 3200 的一半），镜头跟着主角走；五层视差（天空大海静止 / 远山 .35 / 后排房子 .7 / 主层 / 前景草丛和叶丛画在人物前面）；高台 A（x 200~440，顶面 252，树屋）、木栈台（x 640~736，顶面 224）、高台 B（x 1380~1600，顶面 252，传送门）都是平台，可以跳上去。和关卡里一样能走、跳、普攻、放技能（没有怪，生命和魔力始终满）。站在 NPC、熔炉、女神像或传送门前按 W 互动（要站在同一高度），点击不再有效。从左到右：村长 x=70、技能导师 x=340（高台 A 上）、药剂师 x=600、仓库管理员桂婶 x=700(第三十二轮,中年女性;仓库 100 格 R19.wh,背包和仓库之间存取装备;关卡里背包满了装备留在地上,只提示「背包已满」)、女神像 x=820（广场，通关第二关后出现）、装备商人 x=985、强化师 x=1195、熔炉 x=1265、传送门 x=1500（高台 B 上）。装饰：路灯（夜光）、栅栏、长椅、花丛、路牌、水井、彩旗串、木箱、铁砧、工具架。
	•	飞行：装备翅膀后，在空中再按一次跳跃起飞。W / S 控制升降，A / D 控制方向，不按就悬停；飞行每秒消耗魔力。
	•	GM：电脑上依次按 F2 F3 F1 F2 F3 F3 打开（两次按键间隔不超过 3 秒），界面上没有任何提示。
