我在做单文件 HTML5 Canvas 横版 RPG《无名之旅》。开发包里:
  src/game.src.html  源码(图片已抽出,用 @@A:名字@@ 占位)   assets/  内嵌图片(png)
  tools/build.py     拼成单文件 out/无名之旅.html,并生成 CODEMAP.txt(函数 / 模块 → 行号)
  tools/split.py     反向:把单文件拆回 src + assets      tools/fetch_assets.sh  重新下载美术素材源
  tests/smoke.py     冒烟测试(只测默认配置:1920×1080、像素美术、LPC、剑士;只收集控制台错误)
  art_src/           各素材的生成脚本和图集          docs/  交接(本文件)、说明_当前设定、更新记录、旧规格归档

【规矩】
- 全程简体中文。只做电脑端(手机端代码 2026-10-12 已删除)。
- 先看 CODEMAP.txt 定位,再用 grep / sed 读相关几段;不要整读源码和文档。《说明_当前设定》按需 grep 对应小节。
- 素材:先 grep docs/素材清单.txt(assets → 源码行 / 生成脚本 / 来源授权)和 docs/原始素材索引.txt(raw 包内容),build.py 自动更新;不要列 raw 目录、不要打开图片 / 音频。
- 改 src/ 后跑 build.py;交付前跑 tests/smoke.py(零错误)。只在改了画面时截图,而且只截相关区域、合成一张看。
- 交付:用 SendUserFile 发 out/无名之旅.html 和新的「无名之旅_开发包.zip」;文档只更新《交接》的「当前状态 / 下一步」和《更新记录》顶部一段(3~8 行),《说明_当前设定》只改受影响的行。
- 开源素材必须在设置页「美术致谢」写明作者、链接、授权、改动;只用 CC0 / CC-BY / OGA-BY(不用 CC-BY-SA / GPL)。
- 新的像素模块只写像素画法,不再做原版几何兜底(已有的兜底代码留着不动);NPC 男女老少不能弄混。
- 用户已授权:有更省额度的做法可以直接执行,不用先问。

【环境】本机(Windows)可以直接从 opengameart.org、github.com 下载(PowerShell Invoke-WebRequest);GitHub API 有频率限制,改用 releases 页面。
