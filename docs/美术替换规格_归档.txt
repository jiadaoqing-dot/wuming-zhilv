=====================================================================
状态:v1.5 — 第 1~4 步完成;第 5 步主角改用 LPC 素材(见文末「进度记录」)
日期:2026-10-11
本文件目的:把"用像素精灵逐步替换纯 Canvas 几何美术"的决策、素材、技术规格、
分步计划和风险写清楚。你确认后才进入第 1 步。

术语约定(重要)
  · 游戏里已经有"精灵"系统(代码里的 SPR / sprNew / SPRP,是伙伴精灵,可吸收装备)。
  · 本文档里说的"像素精灵图"统一写作"角色图"或 sprite,代码命名空间用 PXA,
    避免和游戏里的"精灵"系统重名。

---------------------------------------------------------------------
一、已确定的决策
---------------------------------------------------------------------
 1. 只做 PC 端(2026-10-11 你已确认取消手机端)。以后只测桌面,不再测手机视口。现有手机控件代码先保留不删,不再维护。
 2. 画风:粗像素(方案 A),一个美术像素 = 屏幕上 N×N 个整数像素。
 3. 逻辑分辨率保持 640×360(世界宽 3200,地面 GY=300)。输出按整数倍放大:
    ×2=1280×720,×3=1920×1080,×4=2560×1440,×6=4K。窗口不是整数倍时留黑边。
 4. 动画方式:逐帧精灵。基线每个动作 2~3 帧,不够的动作再补帧或换素材。
 5. 角色外观:主角原用 Ars Notoria,2026-10-11 第 5 步改为 LPC(Ars 保留为设置选项);NPC 用 Sara 和 Trevor(以及后续补充的素材)。
 6. 发型只改颜色,不做发型形状变化。
 7. 剑士和法师是同一个角色:剑士 = 护甲 + 头盔 + 盾,法师 = 长袍 + 帽子 + 书。
    切换武器 = 换装(游戏里 L 键切换,可随时切换),技能导师对话里补一段双形态说明。
 8. 技能特效不重新设计,继续用程序绘制,再经过"统一像素管线"变成像素风。
 9. 每一步都保留旧的几何绘制作为回退(开关控制),关闭开关时画面与现在完全一致。
10. 范围:最终全部替换,顺序为主角 → NPC → 小怪 → Boss → 特效/UI/背景/图标。
    本阶段只做到第 1~3 步(基础设施 + 主角)。

三、技术规格
---------------------------------------------------------------------
1. 绘制尺寸与锚点
   · 主角单格 46×50。实测站立身形约 22 宽 × 45 高(格内 x=12~33,y=3~47),
     脚底在第 47 行;锚点取"脚底中心"(格内约 x=23,y=48)。
   · 素材默认面朝右;面朝左用水平翻转。
   · 判定框保持现有数值不变(主角 24×32 等)。画面和判定解耦:
     精灵只负责画,不参与碰撞。
   · 在 640×360 画面里,主角身形约占屏幕高度的 12%。

2. 素材格式与加载
   · 先把所有素材整理成透明 PNG,再转成 base64 内嵌进 HTML,保持"一个文件双击就能玩"。
     估算:Ars 全部素材约 150~300 KB,内嵌后约增加 0.3 MB。
   · 不用外部文件的原因:file:// 方式打开时,浏览器会拦截读取像素(换色用)和读取 JSON。
     data URL 不受影响。
   · Sara 和 Trevor 的洋红底用 #FF00FF 抠成透明,离线处理好,不在游戏里实时抠。
   · 新增一个独立模块,命名空间 PXA,包含:图集定义、帧时长表、锚点表、
     加载器、绘制函数 PXA.draw(ctx, 角色, 动作, 帧, x, y, 朝向)。

3. 换色(调色板替换)
   · 品质(普通/精良/稀有/史诗):装饰色或高光色按品质色偏移;稀有和史诗额外加轮廓光。
     具体做法在第 2 步原型里试,先做出对比图再定。
   · 系列(旅者/林王/荒漠…):选定对应的 armor 和 robe 编号(8 套够用),
     不够的系列用换色补。
   · 发色:把底图的头发像素换成 HAIRS 里的颜色(目前 3 种,以后加色很容易)。
   · 换色结果在加载时生成并缓存,不在每一帧里算。

4. 统一像素管线
   · 做法:先把要像素化的内容画到 640×360 的离屏画布,再用最近邻放大到输出尺寸。
     渐变、半透明光晕会被量化成几档颜色;文字和界面单独画在高清层。
   · 技术决策点 T1:2026-10-11 已定 P2(分层),见进度记录第 4 步。
       P1 全局低分辨率:整个游戏都先画到 640×360 再放大。
          优点:全局统一。缺点:过渡期旧的矢量怪物和背景会变粗。
       P2 分层:背景和矢量怪物保持高清,精灵和特效走像素层叠在上面。
          优点:过渡期好看。缺点:精灵和矢量怪物的前后遮挡关系要特殊处理。
   · 特效风格规则:取色自角色调色板,每个特效 3~4 色加描边;动画 10~12 帧/秒步进;
     命中白闪 1~2 帧,配合现有的 hitstop 和屏幕震动。

5. 渲染与时间
   · 动画按实际时间(秒)推进,与刷新率无关(你的显示器是 144Hz,所以不能按帧计数)。
   · 每个动作的帧时长是数据,可调;可以让关键帧停留更久(hitstop 式的重点停顿)。

6. 存档
   · 存档键 wuming-save-v1 不变。美术替换不改存档结构。

四、主角动作映射(Ars Notoria 的 28 帧)
---------------------------------------------------------------------
格子编号 = 行×8+列。以下是我对图的读法,第 2 步原型要用实物确认。
  0     站立(待机)
  1     跪姿 / 蹲伏
  2~5   拳击四连帧:起手、出拳、出拳持续、收招
  6~7   跳跃 / 空中姿势
  8~9   受击:后仰、蹲伏受击
  10~13 提膝出拳(可当空中攻击)
  16    被击飞在空中
  17    倒地
  18~21 低姿态出拳:起手、出拳、持续、收招
  24~31 跑步 8 帧
游戏状态 → 帧的映射(首版草案):
  待机 → 0,可加 1 个呼吸微动(代码做 1px 上下浮动)
  走和跑 → 24~31(走路用同一组、降低播放速度)
  起跳、下落 → 6~7
  剑士普攻 1~3 段 → 2~5、18~21 轮换,叠 sword-slash 刀光
  法师普攻 → 2~5,叠 staff-attack
  蓄力 → 帧 2 停留
  受击、僵直 → 8~9
  击飞、死亡 → 16、17
  城镇行走 → 同跑步组降速
  飞行(翅膀)→ 6~7 + 翅膀图层(见风险 R6)
  20 多个技能的专属姿势 → 没有对应素材。首版做法:复用上面的帧,
    配合代码做位移、旋转、压扁拉伸、残影(现有的 ghost),
    由特效(像素化后)承担冲击感。哪个技能看着别扭,
    再单独补帧,逐个技能做表。

六、NPC 规格(重点:性别和年龄不能弄混)
---------------------------------------------------------------------
规则:
  · 女性、男性、老人是三种不同的外观,换色不能跨性别或跨年龄。
  · 老年角色必须有明显特征:白发、胡须、拐杖、略驼背,在 32×48 下做得到。
  · NPC 只需要:站立(2~3 帧待机)、说话、领任务和完成任务的欢呼,
    不需要战斗帧,手工修改的工作量很小。
现有 NPC 与分配:
  技能导师 艾琳    女性,成年  → Sara(原色,蓝衣金发)
  药剂师 小葵      女性,较年轻 → Sara 换色变体(换发色和衣色),手里拿药瓶。
                    风险:和艾琳撞脸。后续找到第二个女性素材后替换。
  强化师 铁叔      男性,中年  → Trevor 换色,手工加络腮胡,衣服换成工匠色。
  装备商人 老金    男性,偏老(跑商,30 年前当过向导)→ 目前没有合适素材。
                    需要另找中老年男性素材,或在 Trevor 基础上手工改
                    (白发 + 胡须 + 微驼背 + 背包)。
  村长             男性,老年,白发白胡须、拿拐杖 → 目前没有合适素材。
                    同上,需要另找或手工改。
 结论:现有素材覆盖 1 位女性、1 位年轻男性;还缺 1 位年轻女性、2 位老年男性。
